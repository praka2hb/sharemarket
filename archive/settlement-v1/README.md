# Archived: settlement version (v1)

The quarterly-settlement design: per-quarter series, FilingResolver (bonded proposals, challenges,
arbiter, fallback), CloseHook (stops trading before results), the settlement replay script and the
settlement rule document. It was built, tested (80 tests) and deployed on Base Sepolia, then dropped
on 2026-11-15 in favour of a perpetual split with no settlement. See docs/decisions/0001-drop-settlement.md.
